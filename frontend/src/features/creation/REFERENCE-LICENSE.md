# Creation Workspace Reference

The media workspace adapts the workflows and interaction structure of
[pigzwy/chat-vue](https://github.com/pigzwy/chat-vue) at commit
`80649c38cb40ceeba191161cfddd9d6d83d85f1f` to Sub2API's Vue components,
authentication, group selection, billing and storage boundaries.

Reference files include `src/pages/studio.vue`, `src/components/studio/`,
and `src/composables/studio/useStudioTasks.ts`. The upstream license is
retained below for adapted portions. This does not import upstream branding,
hard-coded provider groups, prices, user data, or gallery assets.
