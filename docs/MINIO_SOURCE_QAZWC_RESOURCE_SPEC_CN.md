# MinIO 与 `source.qazwc.com` 资源域名规范

本文档约束资源承载、部署和验收，覆盖头像、公告、工单、AI、论坛图片。

## 1. 总原则

- MinIO 是统一对象存储。
- `source.qazwc.com` 是统一资源访问域名。
- 外部用户不直接访问 MinIO 内网地址、端口或桶域名。
- 资源是否公开，和账号是否可选，是两条独立的治理维度。

## 2. 统一承载范围

以下资源统一进入 MinIO：

- 头像
- 公告图片
- 工单图片
- AI 生成图片
- 论坛图片

不建议为每个业务再额外引入独立文件域名，否则会带来权限、缓存、审计和回收口径分裂。

## 3. 域名与路径规范

### 3.1 唯一入口

- 所有对外资源访问统一使用 `https://source.qazwc.com/...`
- 页面、接口、富文本、通知消息都不要回传 MinIO 直链
- 如果底层是对象存储直读、签名 URL 重写或业务代理，外部看到的域名都应保持为 `source.qazwc.com`

### 3.2 路径建议

建议统一采用一个主桶，再按前缀隔离：

- `avatars/{user_id}/...`
- `announcements/{announcement_id}/...`
- `tickets/{ticket_id}/...`
- `ai/{yyyy}/{mm}/{dd}/{user_id}/...`
- `forum/{topic_id}/...`

如果业务量很大，也可以拆桶，但对外域名仍保持单域名：

- `source.qazwc.com/avatars/...`
- `source.qazwc.com/ai/...`

## 4. 公开与私有资源规范

### 4.1 公开资源

适用场景：

- 公开头像
- 公开公告配图
- 论坛公开图片
- 明确允许外链的 AI 成品图

要求：

- 使用稳定 URL
- 通过 `source.qazwc.com` 访问
- 配置明确的缓存头和内容类型

### 4.2 私有资源

适用场景：

- 工单附件
- 用户私有 AI 作品
- 未发布或待审核内容

要求：

- 仍然通过 `source.qazwc.com` 暴露
- 使用短时效签名 URL，或通过业务代理二次鉴权
- 不返回 MinIO 原始签名域名给前端

## 5. MinIO 部署基线

### 5.1 连接模式

- 优先使用 S3 兼容方式接入
- MinIO 场景建议开启 path-style
- 对需要对象存储配置的业务，统一复用一套凭据策略和审计策略

### 5.2 安全要求

- Access Key / Secret Key 仅保存在服务端
- 桶默认私有
- 公共访问通过资源域名和网关策略显式放开
- 开启服务端审计日志和对象生命周期策略

### 5.3 运维要求

- 对公开资源设置缓存策略
- 对私有资源设置签名 TTL
- 对 AI 临时文件设置自动回收周期
- 定期核查跨业务前缀是否串读

## 6. `source.qazwc.com` 部署基线

### 6.1 DNS 与 TLS

- `source.qazwc.com` 必须配置稳定 DNS 解析
- 必须启用 TLS
- 必须把证书续期、域名解析和回源健康检查纳入监控

### 6.2 反向代理

- 可直接反代 MinIO，也可反代资源网关
- 代理层要保留正确的 `Content-Type`、`Content-Disposition` 和缓存头
- 下载与预览接口要区分直出和签名下载

### 6.3 缓存与 CORS

- 对公开资源配置缓存头
- 对动态签名下载避免长缓存
- 若前端跨域访问，CORS 只开放必要来源

## 7. 推荐落地流程

### 7.1 管理员

1. 创建 MinIO 桶或统一资源桶。
2. 规划资源前缀。
3. 配置 `source.qazwc.com` 反向代理到资源层。
4. 确认公开/私有访问策略。
5. 通知前端与业务侧只使用 `source.qazwc.com`。

### 7.2 运维

1. 为 `source.qazwc.com` 配置 TLS。
2. 配置缓存、CORS、内容类型和大文件限制。
3. 对私有资源启用签名或鉴权代理。
4. 配置备份、复制、告警和生命周期。

### 7.3 开发

1. 资源写入统一落 MinIO。
2. 数据库存储 `source.qazwc.com` 路径或资源键，不存内网地址。
3. 任何新图片业务默认进入统一资源规范。

## 8. 验收清单

### 8.1 部署验收

- `source.qazwc.com` 可解析、可 HTTPS 访问。
- 公开资源可直接预览。
- 私有资源不能通过裸链长期公开访问。
- 签名下载可在过期后失效。
- 资源响应头包含正确的 `Content-Type`。
- 缩略图与原图路径分离且可分别访问。

### 8.2 业务验收

- 头像、公告、工单、AI、论坛图片都走同一个资源域名。
- AI 创作中心产物能写入 `ai/` 前缀。
- 论坛与公告资源不会回落到独立图片域名。
- 前台页面和接口返回值里不出现 MinIO 原始地址。

### 8.3 安全验收

- MinIO Access Key/Secret Key 不落前端。
- 桶默认私有。
- 公开资源和私有资源的缓存策略不同。
- 公开资源没有被错误暴露工单附件或私有 AI 作品。
- 生命周期规则能清理临时文件和过期对象。

## 9. 回归检查清单

1. 新增一个 AI 图片作品，确认返回 `source.qazwc.com` 链接。
2. 上传一个工单附件，确认无法用公开 URL 长期直链访问。
3. 上传一个公开公告图，确认可以直接打开且缓存头生效。
4. 把同一对象改回私有后，确认公开 URL 失效或改为受控访问。
5. 检查前端、通知和富文本中没有任何 MinIO 内网地址。

## 10. 当前后端落地口径

- 资源域名 `source.qazwc.com` 统一反代到后端，不直接暴露 MinIO。
- 公开资源走 `GET /api/v1/media/public/:id` 和 `GET /api/v1/media/public/:id/thumbnail`。
- 私有资源通过 `GET /api/v1/media/download/:id` 和 `GET /api/v1/media/download/:id/thumbnail` 的短时签名 URL 访问。
- 上传、详情、删除、公开/私有切换由 `/api/v1/media/*` 统一承载，桶保持私有，MinIO 仅作为内网对象存储。
